# 🀄 LLKAN 连连看

> 南方科技大学 CS09 课程期末项目（2015 年春季学期）
> 基于 **Java Swing** 开发的桌面连连看小游戏

## 项目简介

LLKAN 是一个经典的「连连看」桌面小游戏：玩家需要在棋盘上找出**图案相同且能在不超过两次拐弯的通道内连通**的两个棋子，点击后将其消除，直到清空全部棋子即为通关。项目包含完整的用户系统、双难度、排行榜、存档与主题皮肤等扩展功能。

## 功能特性

- **两种难度**
  - 简单模式：11×11 棋盘，16 对棋子
  - 困难模式：12×12 棋盘，50 对棋子
- **经典连线规则**：支持 0 折（直线）、1 折、2 折路径消除，连线必须经过空格通道
- **提示功能**：一键高亮一对可消除的棋子（2 秒后自动消失）
- **计时与计分**：每局 180 秒倒计时；按连消加成计分（每次消除 +连消数×10 分）
- **连消系统**：3 秒内连续消除可叠加连消数
- **用户系统**：注册 / 登录 / 登出，支持游客模式；登录后主题偏好自动保存恢复
- **排行榜**：通关成绩自动写入，支持查看 Top 20
- **存档 / 读档**：登录用户可使用 3 个存档槽位保存/恢复游戏进度
- **双主题皮肤**：麻将牌风 / 卡通动物风，背景图随主题切换
- **音效与背景音乐**：点击、消除音效 + 循环背景音乐（JLayer 播放 MP3）
- **通关结算**：清空所有棋子后弹出通关结算弹窗

## 运行环境

- **JDK 11+**（代码使用了 `String.isBlank()` 等新特性）
- 依赖库：`lib/jlayer-1.0.1.jar`（MP3 解码播放，已随仓库提供）

## 如何运行

### 方式一：IntelliJ IDEA（推荐）

1. 用 IntelliJ IDEA 打开项目根目录
2. 源码根目录已配置为 `src/`，主类为 `src.app.Main`
3. 直接运行 `Main` 类即可启动

### 方式二：命令行

在**项目根目录**下执行（需保证相对路径能读取 `resource/` 下的图片与音乐）：

```bash
# 编译（Windows 类路径分隔符为 ;，macOS/Linux 为 :）
javac -encoding UTF-8 -cp "lib/jlayer-1.0.1.jar" -d out -sourcepath "src" "src/src/app/Main.java"

# 运行
java -cp "out;lib/jlayer-1.0.1.jar" src.app.Main
```

## 操作说明

1. 点击选择**第一个棋子**（红色边框表示选中）
2. 再点击**同图案且可连通**的第二个棋子，若连通则绘制连线并消除；若不可连通，第二格会变为新的选中格
3. 顶栏实时显示：剩余对数 / 倒计时 / 当前分数 / 连消数
4. 底部按钮：`重新开始` / `返回菜单` / `提示` / `保存存档`
5. 清空全部棋子即通关；倒计时归零则游戏结束

## 项目结构

```
LLKAN
├── src/                     # 源码根目录
│   └── src/
│       ├── app/             # 程序入口（Main）
│       ├── model/           # 数据模型（Cell、GameBoard、Position、Line 等）
│       ├── ui/              # 界面层（MainFrame、MenuPanel、BoardPanel、StatusPanel、登录/排行榜弹窗等）
│       ├── user/            # 用户与数据持久化（UserManager、SaveManager、LeaderboardManager）
│       └── utils/           # 工具层（连线算法 Utils、主题 ThemeManager、音频 AudioManager）
├── resource/                # 游戏资源（图片 images/、音乐 music/）
├── lib/                     # 第三方依赖（jlayer-1.0.1.jar）
├── out/                     # 编译输出（已忽略，不入库）
└── .gitignore
```

## 技术栈

| 技术 | 用途 |
|---|---|
| Java + Swing | GUI 界面与事件交互 |
| JLayer（jlayer-1.0.1） | MP3 背景音乐与音效播放 |
| Java 对象序列化 | 本地持久化（用户数据、排行榜、游戏存档） |

## 数据存储说明

- 用户数据（`users.dat`）、排行榜（`leaderboard.dat`）、游戏存档（`saves/`）以本地文件形式保存在**程序运行目录**下
- 以上均为运行时生成的数据，已通过 `.gitignore` 排除，不随仓库上传
